# Notes

Detailed study notes in Markdown, organised by paper, subject and sub-subject. They follow `.claude/CONTENT_GUIDELINES.md`: each topic file starts with front-matter (sources, PYQ references, images needed, to-do) and contains a summary, core notes, tables, flowcharts, timeline, memory tricks, pictures with sources, "Remember this", "Common confusions", a solved example and a quick revision.

Pictures are taken from the textbooks in `Books/` and are stored in `study-app/public/images/`. NCERT pictures are for private study only; do not publish them.
